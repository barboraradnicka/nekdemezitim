DŮLEŽITÉ PŘED ODESLÁNÍM URL GOPAY
1) Otevřete index.html v textovém editoru a vyhledejte "DOPLŇTE".
2) Doplňte veřejné kontaktní údaje prodávajícího:
   - kontaktní e-mail
   - telefon
   - jméno / obchodní označení
   - IČO
   - sídlo
3) Ověřte oba právní odkazy:
   - Obchodní podmínky
   - Ochrana osobních údajů
4) Ověřte SimpleShop formuláře:
   - 1 měsíc: Aa4YL
   - 3 měsíce: oPR24
   - 6 měsíců: 0Ma5P
   - 12 měsíců: 9XlzE
5) U každé varianty proveďte test kliknutí. Po kliknutí se má pod stránkou zobrazit příslušný vložený SimpleShop formulář.
6) Finální tlačítko v SimpleShopu musí zůstat "Objednávka zavazující k platbě".
7) Až bude GoPay schváleno a zapojené v SimpleShopu, zkontrolujte, že se v objednávce nabízí platba kartou.

PUBLIKACE ZDARMA — GITHUB PAGES
- založte bezplatný účet na github.com
- vytvořte nový PUBLIC repository, např. "nekdemezitim"
- nahrajte obsah této složky (index.html, styles.css a složku assets)
- Settings > Pages
- Source: Deploy from a branch
- Branch: main / root
- Save
- výsledná adresa bude přibližně:
  https://UZIVATELSKEJMENO.github.io/nekdemezitim/

Poznámka:
GitHub Pages je statický hosting. SimpleShop objednávkový formulář je do webu vložen přes oficiální JavaScript SimpleShopu.
